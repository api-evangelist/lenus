# Lenus eHealth

> Lenus eHealth is a Copenhagen-headquartered health-and-fitness technology company that operates a
> closed, invitation-based coaching platform for online health and fitness coaches. Coaches run their
> businesses — client onboarding, training and nutrition programming, progress tracking, messaging,
> billing and content — through Lenus' web dashboard and consumer mobile apps. Lenus publishes no
> public API, developer portal, SDKs or machine-readable specifications; the platform is accessed
> through its own applications under a coaching partnership. This file was generated by the API
> Evangelist enrichment pipeline from the public web surface, not from a provider-published llms.txt.

## API surface

Lenus eHealth does not publish a public API. Probed and confirmed absent as of 2026-07-19:

- No developer portal or documentation host (developer./docs./developers. subdomains do not resolve).
- No OpenAPI, Swagger, GraphQL or AsyncAPI definition at any public path.
- `api.lenus.io` resolves but returns HTTP 302 to the marketing site; it is not a public API surface.
- No `/.well-known/` discovery documents on any host.
- No first-party client libraries on npm, PyPI, or other public package registries.

## Disambiguation

Lenus eHealth (lenus.io / lenusehealth.com, Copenhagen, Denmark — fitness and health coaching) is a
DIFFERENT company from Lenus Health (lenushealth.com, Edinburgh, Scotland — an NHS-facing digital
health platform that does publish developer documentation and integration samples at
https://github.com/lenushealth). Do not merge the two.
